# タスク一覧
## 一、　テスト編集とMockで真実払い環境を差し替える
1. 微信ログインモック (MockWechatLoginGateway)
- ダミーのQRコードとトークンを返却し、外部サービスなしでログイン処理を検証。
2. 支付宝決済モック (MockPaymentGateway)
- 注文作成 → コールバック → 決済成功の一連の流れをシミュレーション。
3. タイムアウト短縮
- 注文自動キャンセルの時間を30分から30秒に短縮し、テストを迅速化。
4. 在庫の単体テスト
- DeductHandler と RestoreHandler のテストを作成し、在庫の引き落とし・復元を保証。

効果: 「注文 → 決済 → コールバック → 履約 → タイムアウト処理」の全链路が外部サービスなしでテスト可能になります。
